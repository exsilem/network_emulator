# Network Emulator

## 1. Описание проекта
**Network Emulator** — инструмент для эмуляции передачи UDP-пакетов через виртуальный канал связи с настраиваемыми характеристиками: задержкой, джиттером, потерями пакетов и пропускной способностью.  
Подходит для тестирования работы кодеков, протоколов и приложений в условиях нестабильной сети, включая эмуляцию спутниковых каналов.

Проект также содержит инструменты для:
- анализа реальных данных и подбора функций распределения (`fitter.py`);
- генерации тестовых CSV-файлов с распределениями (`generate_test_data.py`).

## 2. Структура проекта и функционал

### **main.py**
Главная точка входа в программу.

**Функции:**
- **`main()`**
  - Загружает конфигурацию из `config.json`.
  - Запускает два сервера `PacketServer` для передачи в обе стороны.
  - При необходимости запускает веб-интерфейс управления параметрами.
  - Обрабатывает остановку по `Ctrl+C`, останавливает серверы, сохраняет отчёты.

### **config.py**
Хранит параметры канала и методы загрузки.

#### Класс **`ChannelConfig`**

 Полное описание полей

**Основные сетевые параметры**
| Поле | Тип | По умолчанию | Единицы измерения | Описание |
|------|-----|--------------|-------------------|-----------|
| `server_ip` | str | `"127.0.0.1"` | - | IPv4-адрес сервера в формате строки |
| `encoder_port` | int | `5001` | - | Номер порта для encoder (0-65535) |
| `decoder_port` | int | `5002` | - | Номер порта для decoder (0-65535) |

**Параметры потерь**
| Поле | Тип | По умолчанию | Единицы измерения | Описание |
|------|-----|--------------|-------------------|-----------|
| `packet_loss` | float | `0.0` | доля единицы (0.0-1.0) | Вероятность потери пакета |

**Параметры задержки**
| Поле | Тип | По умолчанию | Единицы измерения | Описание |
|------|-----|--------------|-------------------|-----------|
| `delay_min_ms` | float | `0.0` | миллисекунды | Минимальная задержка передачи |
| `delay_max_ms` | float | `0.0` | миллисекунды | Максимальная задержка передачи |
| `delay_distribution_type` | str | `"uniform"` | - | Тип распределения (`uniform`/`normal`/`exponential`) |
| `delay_param1` | float | `None` | зависит от типа | Для normal: μ (мс), для uniform: min (мс) |
| `delay_param2` | float | `None` | зависит от типа | Для normal: σ (мс), для uniform: max (мс) |
| `delay_distribution_file` | str | `None` | - | Путь к файлу с кастомным распределением |

**Параметры джиттера**
| Поле | Тип | По умолчанию | Единицы измерения | Описание |
|------|-----|--------------|-------------------|-----------|
| `jitter_distribution_type` | str | `"normal"` | - | Тип распределения джиттера |
| `jitter_mu_ms` | float | `0.0` | миллисекунды | Среднее значение джиттера |
| `jitter_sigma_ms` | float | `0.0` | миллисекунды | СКО джиттера |
| `jitter_distribution_file` | str | `None` | - | Путь к файлу с кастомным распределением |

**Параметры пропускной способности**
| Поле | Тип | По умолчанию | Единицы измерения | Описание |
|------|-----|--------------|-------------------|-----------|
| `bandwidth_bps` | int | `10_000_000` | бит/секунду | Максимальная пропускная способность канала |
| `bandwidth_distribution_file` | str | `None` | - | Путь к файлу с распределением bandwidth |

**Пример полной конфигурации**
```json
{
  "server_ip": "192.168.1.100",
  "encoder_port": 6000,
  "packet_loss": 0.01,
  "delay_min_ms": 10.5,
  "delay_max_ms": 50.2,
  "jitter_mu_ms": 2.0,
  "jitter_sigma_ms": 0.5,
  "bandwidth_bps": 5000000
}
```

#### Функция **`load_json(path: str) -> ChannelConfig`** 
- Загружает конфигурацию из JSON-файла.
- Возвращает объект `ChannelConfig`.

### **server.py**
Модуль, эмулирующий передачу UDP-пакетов с задержками, джиттером, потерями и ограниченной пропускной способностью.
#### Назначение
Реализует UDP-сервер для:
- Приема фрагментированных пакетов
- Эмуляции сетевых характеристик (задержки, потерь, джиттера)
- Пересылки пакетов целевому узлу

#### Константы
```python
FRAG_HEADER_SIZE = 8  # bytes (4B packet_id + 2B fragment_index + 2B total_fragments)
MAX_PAYLOAD_SIZE = 1200  # bytes (макс. размер полезной нагрузки фрагмента)
```
#### Класс **`PacketServer(threading.Thread)`**
Принимает пакеты, при необходимости собирает их из фрагментов, моделирует задержку и джиттер, передаёт их дальше.
  - **`__init__(ip: str, port: int, forward_ip: str, forward_port: int, config: ChannelConfig, monitor: TrafficMonitor, role: str)`**
    - Инициализирует сервер с заданными параметрами.
    - Загружает распределения из CSV (если есть)
    
**Параметры:**

| Параметр | Тип | Описание |
|------|-----|--------------|
ip  | 	str	 |  IP-адрес сервера
port | 	int | 	Порт сервера
forward_ip | 	str | 	Целевой IP для пересылки
forward_port | 	int | 	Целевой порт
config | 	ChannelConfig | 	Конфигурация сети
monitor | 	object | 	Объект для логирования
role | 	str | 	Роль ('encoder'/'decoder')
**Поля класса:**
 | Поле | 	Тип	 | Описание | 
 |------|-----|--------------|
buffers	 |defaultdict |	Буферы сборки пакетов
delays_iter |	cycle/None |	Итератор задержек из CSV
jitter_iter |	cycle/None |	Итератор джиттера из CSV
bandwidth_iter |	cycle/None |	Итератор bandwidth из CSV
#### **Методы:**
  - **`_load_csv_iter(path: str) -> itertools.cycle | None`**
    - Загружает значения из CSV-файла в список и создаёт бесконечный итератор.
  - **`_process_complete_packet(packet_id: str, data: bytes)`**
    - Рассчитывает задержки и джиттер, логирует результаты, отправляет пакет.
  - **`run()`**
    - Основной цикл приёма данных:
      - Получает фрагменты пакета.
      - Собирает их, пока не придут все части.
      - Передаёт полный пакет в `_process_complete_packet()`.
  - **`stop()`**
    - Останавливает поток и закрывает сокет.

#### Расчет задержек
При обработке пакета рассчитываются:
- Transmission delay: (размер пакета в битах) / пропускная способность
- Queue delay: Из CSV или случайное значение
- Jitter: Из CSV или нормальное распределение
- Propagation delay: Фиксированное значение из конфига

#### Требования к файлам распределений
- Формат CSV с одним столбцом числовых значений
- Размещение в директории data/distributions/
- Поддерживаемые файлы:
    - delays.csv - значения задержек в мс
    - jitter.csv - значения джиттера в мс
    - bandwidth.csv - значения пропускной способности в бит/с


#### Логируемые параметры
Для каждого пакета логируются:
- Идентификатор пакета
- Расчетное время обработки
- Фактическое время обработки
- Компоненты задержки
- Флаг потери пакета

### **monitor.py**
Модуль для логирования и построения отчётов.

#### Классы:
##### **`TrafficMonitor`**
- Сбора статистики о работе сети
- Логирования параметров обработки пакетов
- Генерации отчетов в текстовом и графическом форматах
- Экспорта данных в CSV

#### Методы
  - **`log_packet(packet_id: str, scheduled_ms: float, actual_ms: float, transmission_ms: float, queued_ms: float, jitter_ms: float, propagation_ms: float, lost: bool)`**
**Записывает данные о переданном пакете.**

| Параметр | Тип | Описание |
 |------|-----|--------------|
packet_id|	str|	Идентификатор пакета|
 |scheduled_ms |	float |	Расчетное время обработки |
actual_ms |	float |	Фактическое время обработки
transmission_ms |	float |	Задержка передачи
queued_ms |	float	 |Задержка в очереди
jitter_ms |	float |	Джиттер
propagation_ms	 |float	 |Задержка распространения
lost |	bool |	Флаг потери пакета


  - **`save_csv(path: str | None = None) -> str`**
    - Сохраняет данные в CSV-файл с временной меткой.
  - **`save_report(path: str | None = None) -> str`**
    - Создаёт текстовый отчёт с:
      - Количеством переданных и потерянных пакетов
      - Средними значениями задержек
      - Разбивкой по видам задержек
  - **`plot_delay_chart(path: str | None = None) -> str | None`**
    - Строит график «заданная задержка vs фактическая задержка» для доставленных пакетов.

#### Структура каталогов 
Модуль сохраняет файлы в директорию data/reports/:


data/reports/
  ├── logs_20231005_123045.csv
  ├── report_20231005_123045.txt
  └── delay_chart_20231005_123045.png

#### Особенности
- Автоматическое создание каталогов при сохранении
- Форматирование даты в имени файла (ГГГГММДД_ЧЧММСС)
- Обработка случаев с нулевым количеством доставленных пакетов
- Использование UTC для временных меток
- Автоматическое закрытие графиков после сохранения

# Вспомогательный модуль для анализа реальных данных задержек, джиттера и пропускной способности!
### **fitter.py**


#### Назначение
Используется для подбора оптимального распределения вероятностей к набору измеренных значений.  
Может работать с любыми CSV-файлами, содержащими один столбец чисел (например, измеренные задержки в миллисекундах).

#### Классы и функции:
- **`fit_distribution(csv_path: str, plot: bool = True)`**
  - Загружает данные из CSV.
  - Использует библиотеку `fitter` или `scipy.stats` для подбора лучшего распределения.
  - Возвращает имя распределения и его параметры.
  - Если `plot=True` — строит гистограмму с наложенной кривой найденного распределения.

#### Пример использования:
```bash
python fitter.py data/raw/delays_real.csv
```

#### Результат:

- Консольный вывод: имя распределения и параметры.
- PNG-график с наложенным распределением (если включён plot=True).
- CSV сгенерированных значений на основе подобранного распределения (опционально).

# Вспомогательный модуль для создания тестовых наборов данных для эмуляции сетевых характеристик!
### **generate_test_data.py**

Скрипт создает тестовые наборы данных для эмуляции сетевых характеристик:

- Генерирует CSV-файлы с распределениями:
    - Задержек (delays.csv)
    - Джиттера (jitter.csv)
    - Пропускной способности (bandwidth.csv)
- Автоматически создает структуру каталогов
- Используется для тестирования и демонстрации работы эмулятора сети

#### Генерируемые файлы
##### 1. delays.csv
- Распределение: Равномерное (uniform)
- Диапазон: 50-150 мс
- Количество записей: 500

**Формат:**

```text
73.45
121.88
58.32
```

##### 2. jitter.csv
- Распределение: Нормальное (Gaussian)
- Параметры: μ = 10 мс, σ = 3 мс
- Особенность: Все значения ≥ 0
- Количество записей: 500

**Формат:**

```text
9.87
12.45
8.12
```

##### 3. bandwidth.csv
- Распределение: Нормальное (Gaussian)
- Параметры: μ = 1 000 000 бит/с (1 Мбит/с), σ = 100 000 бит/с (100 Кбит/с)
- Особенность: Все значения ≥ 100 000 бит/с
- Количество записей: 500

**Формат:**

```text
1054321.22
987654.32
1012345.67
```

##### Структура каталогов
Скрипт создает следующую структуру:

```text
data/
  distributions/
    delays.csv
    jitter.csv
    bandwidth.csv
```
##### Запуск

```bash
python generate_test_data.py
```

##### Особенности
- Автоматическое создание каталогов (os.makedirs)
- Гарантия неотрицательных значений для jitter и bandwidth
- Использование генератора случайных чисел из стандартной библиотеки
- Кросс-платформенная работа с путями
- Чистый CSV-формат без заголовков

##### Использование в проекте
Запустите скрипт перед стартом эмулятора

Укажите в конфигурации `config.json` использование CSV-файлов (в том числе полученные с реального канала):

```json
{
  "delay_distribution_file": "data/distributions/delays.csv",
  "jitter_distribution_file": "data/distributions/jitter.csv",
  "bandwidth_distribution_file": "data/distributions/bandwidth.csv"
}
```

## 3. Установка и запуск
##### 1. Клонировать репозиторий 
``` bash
git clone -b final-version --single-branch https://github.com/exsilem/network_emulator.git
cd .../network_emulator
```

##### 2. Установить зависимости
``` bash
pip install -r requirements.txt
```

##### 3. Настроить config.json (IP, порты, параметры канала).

##### 4.Запустить эмулятор:
``` bash
python main.py
```

##### 5.В отдельной консоли запустить тестовый клиент:
``` bash
python test_encoder.py
```
